================================================================================
HOW TO GET YOUR PEPPERSTONE FIX API PASSWORD
================================================================================

The message format is CORRECT. The issue is the password.

STEP-BY-STEP INSTRUCTIONS:
--------------------------------------------------------------------------------

1. Open Pepperstone cTrader platform

2. Go to: Settings (gear icon) → FIX API

3. You should see:
   - Account Login: 5227001
   - FIX Password: [your actual password]
   
4. The FIX password is NOT the same as your trading password!
   - It's a separate password specifically for API access
   - Usually looks random like: "xK9pQw2m" or similar
   
5. If you don't see a FIX password:
   - Click "Generate FIX Password" or "Enable FIX API"
   - Copy the password that appears
   - Save it somewhere safe!

6. Update the password in your config:
   File: config/brokers/pepperstone_fix.yaml
   Line: password: 5227001_password  ← CHANGE THIS
   
   Change to:
   password: YOUR_ACTUAL_FIX_PASSWORD  ← Use the real one from cTrader

7. Re-run: python execute_pepperstone_gbpjpy.py

================================================================================
ALTERNATIVE: CHECK FIX API STATUS
================================================================================

If FIX API is not enabled:
  → The server will reject logon with RET_INVALID_DATA
  → You need to enable it in cTrader Settings

If you can't find FIX API settings:
  → Contact Pepperstone support
  → Ask them to enable FIX API on account 5227001
  → Request your FIX API credentials
